## **Method 1: Update the driver via Device Manager**

 You can update the driver manually via Device Manager. Follow below steps:

 1) In Device Manager, right click on the device name and select**Properties** . Then Properties Window will open.

![](https://images.drivereasy.com/wp-content/uploads/2016/04/img_571dc41057b15.png)

 2) In “General” tab, click**Update Driver**  button.

![](https://images.drivereasy.com/wp-content/uploads/2016/04/img_571dc462b82b4.png)

 3) Click**Search automatically for updated driver software** . If Windows have drivers for the device, the driver will be updated automatically.

![](https://images.drivereasy.com/wp-content/uploads/2016/04/img_571dc513a4968.png)

 If Method 1 doesn’t work for you, try**[Method 2](https://zebaoaffiliateprogram.pxf.io/xkwqe1)** .

## **Method 2: Use Hardware Id to find the correct driver**

 Windows sometimes fails to provide the proper drivers. If your PCI Simple Communication Controller driver cannot be updated by using Windows, you can use its hardware id to find the right driver. Every device has its own hardware id, so does PCI Simple Communication Controller.

 1) In Properties Window, click**Details** tab.

 2) Under “Property”, select**Hardware Ids** .  

![](https://images.drivereasy.com/wp-content/uploads/2016/04/img_571dc8c03c50a.png)
